Notes on building libusb in linux

The config.h is needed and is generated by running the autogen.sh script located
in the libusb source.  Note, it requires these dependencies:
sudo apt install libtool
sudo apt install libudev-dev

To link with the libudev you will need to add linker option -ludev.
The order of this switch matters, it must be after the libusb object or static
files.  In the wrong order you will see compile error messages such as:
undefined reference to 'udev_new'

If using codeblocks:
1. generate the config.h
2. open your codeblocks project add files select the config.h
3. open your codeblocks project add files select:
libusb/core.c
libusb/descriptor.c
libusb/hotplug.c
libusb/io.c
libusb/libusb.h
libusb/libusbi.h
libusb/strerror.c
libusb/sync.c
libusb/version.h
libusb/version_nano.h
libusb/os/events_posix.c
libusb/os/events_posix.h
libusb/os/linux_netlink.c
libusb/os/linux_udev.c
libusb/os/linux_usbfs.c
libusb/os/linux_usbfs.h
libusb/os/threads_posix.c
libusb/os/threads_posix.h
4. open your codeblocks project,
right-click project,
select Build Options,
select Linker Settings
inside the Linker Options type
-ludev
