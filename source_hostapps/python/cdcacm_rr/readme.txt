Scripts
-------

There are two python scripts:
1. cdcacm_pkt_mt.py
2. cdcacm_pkt_seq.py
The first one is multithreaded, and the second is single threaded.

Requirements
------------

The scripts require the serial module to be installed.

At the command prompt type in:
py -m pip install pyserial

For Ubuntu install using this:
sudo apt-get install python3-serial
